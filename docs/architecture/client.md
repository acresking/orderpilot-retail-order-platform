# Client Architecture

- `src/client/mobile/app.js` is the mobile branch app source.
- `src/client/admin/admin.js` is the company panel source.
- `src/client/shared/styles.css` is shared styling.
- Runtime files under `public/` are generated by `npm run build:web`.

The mobile app supports:

- Browser/PWA.
- Android through Capacitor.
- iOS through Capacitor.

The admin panel supports:

- Browser.
- Electron desktop wrapper.
